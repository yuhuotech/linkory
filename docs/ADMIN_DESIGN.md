# 连信管理后台设计与实施

管理后台独立于用户客户端，复用 Go 模块化单体和 MySQL。前端 `linkory-admin/` 使用 React / TypeScript / Vite，生产构建为静态文件；同源 `/admin/` 托管，管理 API 为 `/api/admin/v1/`，无 Node 生产进程。官方及自建服务均可部署。

## 完整功能范围

1. 概览：账号、设备、在线设备、今日 UTC 消息数、传输任务分布、最近 7 天新增账号/消息/任务、数据库可用性、进程启动时间和中转字节。中转字节是当前进程内计数，明确显示非历史总流量；直连完成任务文件大小也不等于实际中转流量。
2. 用户：搜索、分页、账号详情/设备列表、封禁/解封、撤销全部会话、预览并排队删除消息/传输历史/注销账号。封禁撤销令牌并断开 WS，解封不恢复旧令牌。没有消息正文查看或用户文件下载功能。
3. 设备：按账号/类型/状态筛选、分页，查看平台/版本/在线时间、设备详情、强制下线（撤销会话）、移除设备（同时撤销凭据）。强制下线保留注册身份，可重新登录；移除后旧身份不可直接使用。
4. 传输：按账号/状态/方式/日期筛选、任务详情、失败原因、文件名、大小、耗时，取消非终态任务。列表不包含 SHA 密钥、lan_secret、局域网端点或文件内容。
5. 数据保留：数据库持久化参数（未送达消息默认 30 天，已送达历史/终态传输记录默认不自动删除）；预览影响范围/固定时间界限，确认和理由后创建后台任务；查询任务进度、结果和错误。删除分批执行、崩溃后续跑；账号注销前禁止存在活动文件传输，排队时冻结账号并撤销会话。完成注销删除账号关联数据，审计保留独立目标 ID，不保存正文。
6. 审计：分页、按操作者/动作/目标筛选，记录登录结果、权限拒绝、账号设备操作、策略更新、删除任务创建/执行结果；审计入库失败时管理写操作失败，不默默执行。审计不记录密码、会话 Cookie、CSRF token、消息内容或协商密钥。
7. 管理员：独立账号，不是普通用户，也不注册为设备；管理员/只读运维两角色，页面与服务端双重控制；自助修改管理密码并撤销其它管理会话。管理员通过服务器 CLI 创建/禁用/重置密码/列出（`admin create|disable|passwd|list`），不开放管理员注册。

## 认证与权限

Opaque 随机管理会话，库中保存 token 哈希，最长 8 小时，数据库检查管理员是否启用。Cookie HttpOnly、SameSite=Strict，生产 Secure；本地测试显式关闭 Secure。每个非安全请求校验同源 Origin 与 X-CSRF-Token；登录使用 X-Linkory-Admin 请求头及同源校验，防登录 CSRF。管理员密码 Argon2id，错误登录限流，普通用户 JWT 无权调用后台。没有默认管理员或内置密码。写操作要求非空理由；删除还要求一次性预览 ID（10 分钟有效）与确认文本。

## 运行与部署

新增迁移 `0005_admin.sql`：管理员、会话、审计、策略、预览、任务表及 users.disabled_at。业务令牌校验/登录/刷新检查封禁字段。后台任务由服务端单实例 worker 执行，定时清理使用持久化策略，保留期限以 UTC 创建时间为界。`LINKORY_ADMIN_DIR` 启用后台静态页面；API 不接受 CORS 例外，始终同源。`/admin/` 使用比用户网页版更严的 CSP（仅 `self`，无 WebAssembly、WebSocket、blob、第三方连接）。配置与秘密分离，UI 不编辑 JWT/DB/证书，不展示口令。部署脚本和 nginx 需把 `/admin/`、`/api/admin/` 路由到服务端。

实施顺序：协议 → 数据迁移/认证/服务操作/审计与 worker → 前端 → MySQL 集成测试、构建与浏览器验证。管理后台没有自动加入公网管理员；生产启用需在服务器交互创建管理员。

## 验证记录

使用本机 `LINKORY_TEST_DSN` 的真实 MySQL 完成 `TestAdmin*`：独立会话、只读隔离、普通 JWT 拒绝、CSRF、封禁断开 WS/撤销 refresh、解封、审计失败事务回滚、固定截止删除/预览复用拒绝、账号注销、活动传输禁止注销、设备下线与移除、任务取消终态守卫、管理密码撤销其它会话、登录限流、预览过期和失败任务重试。已有 Go API/WS/文件传输测试一并执行。

本地真实服务端托管生产构建完成浏览器联调：登录/登出、用户封禁与解封、传输筛选及详情、清理范围预览、实际 worker 完成任务、审计列表、只读隐藏写入口、浅深主题及 390px 窄屏。另用真实 API/WS 发送文件并校验接收字节，后台显示任务完成记录。预览环境为测试库，未使用或修改生产账号数据。

封禁/撤销设备时同时取消相关活动文件任务并关闭服务端中转管道；日志审计与实际数据更新同事务。用户登录、消息写入和任务创建持有账号共享锁，管理员冻结/注销持有账号排他锁，防止校验后继续创建关联数据。数据保留参数同时影响离线补发查询和后台清理。

补充验证：`TestAdminAccountRecoveryAndSessions`（CLI 创建校验/重置密码/禁用/会话过期与登出）、`TestAdminLoginGuards`（跨源、缺请求头、5 次失败限流）、`TestAdminReadonlyAuditAndQueries`（只读 403 并入审计、各列表筛选、分页夹取、404/参数校验、策略保存）、`TestAdminRetentionWorker`（定时清理入队不重复、只删符合策略的消息、系统审计）、`TestAdminConsoleStaticAndCSP`。严格 CSP 下用真实 Chrome 登录并浏览各页面，无拦截。
